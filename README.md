# 🤖 Automated Decision Support System

An **AI-powered Automated Decision Support System (ADSS)** built with **n8n workflow automation** to process data, classify decision parameters, generate AI-assisted recommendations, and automate notifications.

The system combines workflow automation, REST APIs, and Large Language Models (LLMs) to create a structured decision-support pipeline with minimal manual intervention.

---

## 🌟 Key Features

* 🧠 **AI-Assisted Decision Support**

  * Uses AI models to analyze decision parameters.
  * Generates recommendations based on processed data.

* ⚙️ **Automated Data Processing**

  * Processes incoming data automatically.
  * Dynamically classifies decision parameters.
  * Reduces repetitive manual processing.

* 🤖 **LLM Integration**

  * Supports connections to local or cloud-based AI models.
  * Sends structured data to LLM endpoints for analysis and recommendations.

* 🔗 **API Integrations**

  * Connect external services through REST APIs.
  * Build automated data flows between different systems.

* 🔔 **Notification Pipeline**

  * Formats decision results automatically.
  * Dispatches updates through the configured notification workflow.

## 🚀 How to Set Up

### 1. Import the Workflow

Import the `.json` workflow file into your local or cloud **n8n** instance.

### 2. Configure Credentials

Set up the required API credentials, authentication tokens, and other secrets using the **n8n Credentials Manager**.

Do not commit private API keys or credentials to the repository.

### 3. Configure AI Integration

Connect the required local or cloud LLM endpoint used by the workflow.

### 4. Activate the Workflow

Enable the workflow by toggling it to **Active** in n8n.

## 🎯 Project Goal

The goal of this project is to demonstrate how **AI and workflow automation** can be combined to support decision-making processes.

Instead of manually processing every incoming parameter, the system creates an automated pipeline that processes information, uses an LLM to assist with analysis, and delivers structured decision recommendations.
