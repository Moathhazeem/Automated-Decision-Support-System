# 🤖 Automated Decision Support System

An intelligent AI-powered decision support system built using n8n workflow automation to analyze, classify, and record decision parameters.

---

## 🌟 Key Features
- **Automated Data Processing:** Classifies incoming data parameters dynamically.
- **LLM Integration:** Connects local or cloud AI models to generate decision recommendations.
- **Notification Pipeline:** Formats and dispatches updates automatically.

---

## 🛠️ Tech Stack
- **Workflow Automation:** n8n
- **Integrations:** REST APIs, LLM Endpoints

---

## 🚀 How to Set Up

1. **Import Workflow:**
   Import the `.json` workflow file into your local or cloud **n8n** instance.
2. **Configure Environment Variables:**
   Set up required credentials and API keys in your n8n credentials manager.
3. **Activate Workflow:**
   Toggle the workflow status to **Active**.
